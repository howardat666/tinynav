## 1. 为什么是圆形 —— 理由不是「方便调试」

现在的方形车：0.28 × 0.35，控制点在驱动轴（车体中心前 0.04）。

```
原地转扫掠半径 = sqrt(0.18² + 0.175²) = 0.251 m
车体半宽                              = 0.175 m
```

**所以「原地转」在方形车上是一个可能撞的动作。** 于是必须逐位姿做足迹碰撞检查、可能被全部
否掉、否掉后只剩倒车、倒车又没有后方障碍图 —— 楔住、摆头、倒车 36 秒这一整类问题都是
这一件事的下游。

**圆盘 + 驱动轴过圆心之后这条链整体消失，而且是可证明的**：圆绕自己圆心旋转，占据区域完全
不变。当前位姿不撞 ⇒ 任意角度的原地转都不撞。**这个证明不依赖半径取多少**，只要半径取全。

顺带的白拿收益（CPU 是板上的第一约束，导航前已 7.67/8 核）：

| | 方形 | 圆 |
|---|---|---|
| 每个位姿的碰撞检查 | 20 个足迹取样点 | **1 次 ESDF 查表** |
| 每周期总查表 | 110 条 × 31 位姿 × 20 = 68,200 | **3,410** |
| 欠采样风险 | 有（闸门 5 点 vs 内核 20 点不一致） | 无，圆的判据是精确解 |

⚠️ **驱动轴每往前偏 1 mm，碰撞半径就 +1 mm** —— 差速车的原地旋转中心固定在驱动轴中点，
圆形碰撞模型的圆心必须取那一点。

## 2. 🔴 碰撞半径是 0.122，不是盘半径 0.1175

**轮子的俯视投影是 25(X) × 65(Y) 的矩形，不是一条线。** 它的角才是整机最远点：

```
sqrt((105 + 12.5)² + 32.5²) = sqrt(117.5² + 32.5²) = 121.9 mm
```

而且那个角在 **z = 32.5 mm（轮毂高度）**，落在障碍 z 波段里，是实打实的材料。

| 件 | 到旋转中心的最大半径 |
|---|---|
| **驱动轮俯视矩形的角** | **121.9** ← 最大 |
| 圆盘 | 117.5 |
| 脚轮甩到最远（偏置 21） | 117.5 |
| 电池角 | 113.6 |
| 相机 / 驱动板 / 支架 / ESP32 | ≤ 93.7 |

🔑 **通用判据：碰撞半径 = 所有件的俯视轮廓到旋转中心的最大距离。**
最容易漏的两个：轮子（俯视是矩形）、脚轮的甩动包络（`|cy| + 偏置距 + 轮半径`）。

考虑过把轮距降到 200.8 让整机真的内切于 Ø235，**不划算**：换来最小可通行缝宽 344 → 335 mm
（9 mm），付出里程计航向刻度敏感度 +5%。

## 3. 三条推导出来的设计定律

### 3.1 盲区恒等式：相机往前挪是纯赚的

相机不能看到自己的盘沿，约束是

```
(光心高 − 板面高) / tan(垂直半视场)  ≥  盘半径 − 光心y
```

每个方案都取**刚好满足**这条的最低相机高度，代回盲区式
`盲区 = 光心y + 光心高/tanθ − 盘半径`，`光心y` **完全约掉**，盲区恒为常数。

→ 相机往前挪，盲区不变，但**光心能低很多、支架能短很多**。

| 光心 y | 最低光心高 | 竖板高 | 整车高 |
|---|---|---|---|
| 0（正中） | 159 | 119 | 177 |
| **+65（当前）** | **111** | **71** | **128** |
| +85（最前） | 92 | 52 | 110 |

🔴 **「相机放在旋转中心最好」这个说法要收窄**：它的理由是**标定方便**（360° 闭合法要找
「相机回到同一位姿」那一帧，偏心画圆会干扰）。对运行时，**纯旋转是视觉惯性里程计的退化
情况**（无平移即无视差无深度），相机偏心在原地转时给出真实平移，**反而略有利**。

### 3.2 脚轮干扰力矩 `M = μ·W·a`，臂长约掉

```
脚轮垂直载荷      F = W·a/L
横向搓动摩擦力    f = μF
对偏航的干扰力矩  M = f·L = μ·W·a      ← L 约掉了
```

→ **减小脚轮造成的航向漂移，唯一的大杠杆是重心离驱动轴的距离 a**；不是脚轮直径，也不是
臂长。漂移还正比于**偏置距 d**（它决定对正过程持续多远）。

这条直接解释了实测：4 米直线横偏 15 cm vs 4 cm，唯一变量是脚轮初始朝向。

### 3.3 三点支撑：重心必须在脚轮那一侧

**重心偏后 ⇒ 脚轮必须在后**，反之亦然。扫地机能用**前**脚轮，是因为它们把驱动轮
**往后挪了**（圆心后 20~25 mm），使得即便质量偏后，重心相对驱动轴仍落在前面。
「驱动轮偏后」和「前脚轮」是同一件事的两面。

## 4. 🔴 重心：算出来余量只有 5%，电池重量是决定性的

| 件 | 质量估 (g) | y (mm) | 力矩 (g·mm) |
|---|---|---|---|
| Looper 相机 | 120 | +59.5 | +7,140 |
| 相机支架 PETG | 77 | +43 | +3,311 |
| 底盘 Ø235×6 | 305 | 0 | 0 |
| 两电机 + 轮 | 240 | 0 | 0 |
| 驱动板 + ESP32 + 线 | 80 | −6 | −480 |
| **电池** | **200** | **−72** | **−14,400** |
| 脚轮（后） | 30 | −84 | −2,520 |
| **合计** | **1052** | | **≈ −7,000** |

**重心 y ≈ −6.7 mm（轴后），重心高 62.9 mm，后脚轮载荷 0.79 N（约 80 g）。**
→ 按 §3.3，**当前配置脚轮必须装后面**。

脚轮不脱地的条件是 `|a| > α·h_cg/g`（与臂长 L 无关）：

| 急停 | 需要 \|a\| | 现在 6.7 mm 的余量 |
|---|---|---|
| 1.0 m/s² | 6.4 mm | **1.05×** ⚠️ |
| 1.5 m/s² | 9.6 mm | 0.70× 🔴 |
| 2.0 m/s² | 12.8 mm | 0.52× 🔴 |

**急停时后脚轮会抬起、车头下扎**，而已量到俯仰变 2.7° 会让 3 m 处的地面剔除偏 0.14 m。

| 电池 | 重心 y | 1 m/s² 余量 |
|---|---|---|
| 150 g | −3.5 | 0.54× 🔴 |
| **200 g** | **−6.7** | **1.05× ⚠️** |
| **270 g** | −10.8 | **1.68× ✅** |
| 350 g | −14.9 | 2.31× ✅ |

**兜底方案：把驱动轴前移**（`axle_y`）。轴前移 e，所有质量相对轴自动后移 e，而 `a_min`
不变 → 余量直接增加 e：

| `axle_y` | 重心在轴后 | 余量 | 碰撞半径 |
|---|---|---|---|
| 0（当前） | 6.7 | 1.05× | 122 |
| **10** | 16.7 | **2.61×** | 132 |
| 15 | 21.7 | 3.39× | 137 |

0.7 m 门洞在 `axle_y=10` 下两侧仍各有 217 mm 净空。这时「原地转恒不撞」仍然成立
（圆心仍取驱动轴、半径取全），只是整车被当成胖了 10 mm。

| 电池 | 100×60 横置 @ (0, −72)，魔术贴 | 它是把重心压到轴后的主要配重 |
| 脚轮 | 底板 38×32，孔 24×20，**前后两组孔都开** @ (0, ±84) | ±84 而非 ±88：给未知的偏置距留余量，能兜住 21 mm |
| 顶面刻线 | 只剩中轴线、驱动轴线、车头箭头 | 电池和脚轮的框已去掉 |

**相机支架 `looper2.scad`**：底板 **110 × 44 × 4**（和竖板同宽，否则竖板两侧只有一条 4 mm
的线贴打印床，必翘边），竖板 110 × 71 × 4，**两条向后的全高翻边** x = ±30 深 18，
M3 × 4 @ (±44, ±16)，相机孔 Ø3.8 间距 95、离底板 55（沿用 `looper.scad` 原值）。

翻边不是装饰：竖板 71 高、端部挂 197 g，4 mm 平板截面惯性矩只有 587 mm⁴，一阶弯曲约
**15 Hz**，正落在底盘振动带里、会直接进 VIO 的惯性测量单元。加翻边后 I = 22,800 mm⁴
（×39），约 **92 Hz**。三角筋只管根部那一小截，翻边整根都在。

**脚轮垫块 `caster_spacer.scad`**：38 × 32 × `plate_bot_z − 35`（名义 15 mm），4 个 Ø3.4，
**100% 填充**。单独打印不做进底盘，三个理由：厚度取决于还没量的板面高度；向下的凸台要么
翻面打（沉孔和立柱就朝下要支撑）要么加支撑（而拆支撑后那个面正是脚轮的安装基准面）；
Ø235 大平板本来就易翘，任何凸台都加风险。

⚠️ **垫块厚度精度直接变成俯仰角：差 1 mm → `atan(1/84) = 0.68°`。**
建议装好后**用相机自己标** —— 深度图拟合地面平面能直接读出俯仰角，按 0.68°/mm 反推。

高度链（`plate_bot_z = 50` 这个估值下，三个轮子最低点都在 −50）：

```
底盘上表面 +6 | 底盘下表面 0 | 垫块 0→−15 | 脚轮底板顶面 −15
脚轮中心 −37.5 | 驱动轮中心 −17.5 | 地面 −50
```

## 6. 电机孔型的真值（曾推错一次）

🔴 曾从「孔在 |x|=90 + 实测轮距 320」反推出 `motor_arm = 70 mm`，**错了**（实测 25）。
那条推理链断在「旧车轮距是靠横向加长件撑出来的」这件事上。

孔型真值，与 `diff_car.scad` 完全自洽（两侧反推出的输出轴都是 60.545）：

```
输出轴夹在两孔之间，一边 9.545、一边 48.455，合计 58
左侧孔组靠后，右侧靠前
```

**这个前后错开是原厂设计的**：原厂轮距只有约 120，孔线在 |x|=35、轴在 60，两个电机机体会在
中间撞上 —— 靠前后错开 38.91 mm 让它们错身而过。我们轮距 210、孔线在 80，机体本来就不撞，
但这个偏置是电机自带的、不可调。

## 7. 沉孔用圆柱不用锥形

| | 锥形（90° 沉头） | **圆柱沉孔** |
|---|---|---|
| 受力 | 🔴 **锥面是楔子**，拧紧在 6 mm 板里产生环向拉应力，PETG 容易沿层间裂 | ✅ 平面承压，只有轴向压力 |
| FDM 精度 | 🔴 打不出锥面，1.8 mm 深 = 9 层台阶，螺钉坐在阶梯上 | ✅ 底面就是一个平面层 |
| 螺钉 | 沉头螺钉 | 内六角圆柱头，更常见、扭矩容量大 |

Ø6.5 × 3.2，剩 2.8 mm 板厚；承压环面 24.6 mm²，200 N 预紧才 8 MPa（PETG 屈服约 50）。
打印上零代价：沉孔是「下小上大」，往上是去材料，无悬垂。

## 8. 脚轮选型（已买）

Ø25 轮、12 mm 轮面、**安装高度 35**、底板 38×32、孔距 24×20、PVC/PU。

| | 评价 |
|---|---|
| Ø25 轮径 | 被动越障约 6 mm。平整室内地板可以，粗线缆/门槛会顶住 —— 这正是**后脚轮**比前脚轮稳妥的理由（后置时 Ø65 驱动轮先遇到障碍） |
| 12 mm 轮面 | 载荷只有 0.79 N，压强约 33 kPa ✅；接触斑小 → 转向轻 ✅ |
| 材质 | **选 PU 不选 PVC**：更软、噪声小、不留痕；振动会直接进 VIO 的惯性测量单元。80~90A |
| 🔴 **转向轴承** | 可用的自对正力矩只有约 **3.6 mN·m**（μ·F·偏置距 = 0.5 × 0.79 N × 9 mm）。**到货第一件事：手指轻拨看能不能自由转到底、不带涩感。** 涩的话它会横着蹭而不转，表现为直线跑偏和原地转卡顿，日志里完全看不出来 |

螺钉：6（底盘）+ 15（垫块）+ 3（脚轮底板）≈ 24 → **M3×25 或 M3×30**。

## 9. 换圆形后要跟着改的软件

| 参数 | 从 | 到 |
|---|---|---|
| `DIFFCAR_CONFIG.shape` | `square` | `circle` |
| `radius` | — | **0.1175**（盘） |
| `collision_radius` | — | **0.122**（驱动轮俯视矩形的角，见 §2） |
| `control_x` | 0.04 | **0** |
| `safety_radius` | 0.1 | **先试 0.05** |
| 固件 `WHEEL_BASE` | 0.3234 | 重标（轮距 0.32 → 0.21） |
| 固件 `WHEEL_CIRC` | 0.2173 | 重标（轮实测 Ø65，不是 Ø70） |
| `obstacle.robot_z_bottom/top` | −0.30 / 0.40 | 按新光心高度平移，保持绝对波段不变 |

⚠️ `safety_radius` **必须重定**：圆形的硬碰撞门限是 `半径 + safety_radius`，0.1 的话门限
0.222，而 0.5 m 门洞的中线 ESDF 只有 0.25，余量剩 28 mm。圆的碰撞判据是精确解，不需要靠
余量去补方形那 20 点取样的漏洞。

轮距重标用 `tool/x5_board/diffcar_spin_closure.py`（转满 360° 找视差过零那一帧，不占地面空间）。

## 10. 反复踩的坑

- 🔴 **干涉检查必须写脚本遍历，不能用眼睛看。** 漏过三次：走线槽吞掉左侧电机孔（只查了右边，
  而左右孔组是前后错开的）、支架底板加宽后压住驱动板和 ESP32、ESP32 的刻线框和左电机沉孔
  相交。检查要覆盖「每个孔 × 每个开口」「每个孔到盘沿/缺口的边距」「孔与孔净距」
  「件两两重叠」「件的角是否掉出圆盘或缺口」「相机视场里有没有自身部件」。
- 🔴 **轮子的朝向**：Y/Z 向 Ø65、X 向 25，和板面共面。按「X 向 65 长」算缺口会差一倍。
  共面 ⇒ 必须开缺口；改成「电机贴盘沿、轮子全在盘外」会把整机撑到 **Ø368，比现在的方形车
  还宽**，是净退步。
- 🔴 **幽灵件和真件要同一份几何。** 垫块一度在底盘里是个近似 `cube`、在自己文件里是带圆角
  带孔的真件 —— 改一个另一个不跟着。现在底盘 `use <caster_spacer.scad>` 调真模块。
  幽灵件一律用 `%`，不进 render 也不进 STL（已验证导出 bbox 仍是 Z 0..11）。
